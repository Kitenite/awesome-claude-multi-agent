# Security Policy

This repository is a curated Markdown list. It ships no executable code, packages, or releases, so there are no supported versions to patch.

The security risk is in what the list links to. A listed project can change owners, publish a compromised release, or have its domain expire and be taken over after it was reviewed.

## What to report

Report privately if a linked project or page:

- Has been transferred to an unknown owner or now serves malware, phishing, or credential-harvesting content.
- Has published a compromised release, install script, plugin, or MCP server package.
- Redirects to a domain unrelated to the original project, such as a typosquatted or expired domain.

Dead links, inactive projects, and quality concerns are not security issues. Use the [Remove entry](https://github.com/Yigtwxx/awesome-claude-multi-agent/issues/new?template=remove-entry.yml) issue form for those.

## How to report

Email <yigiterdogan023@gmail.com> with the entry name, the URL, and what you observed. Do not open a public issue for a suspected compromise.

## What happens next

The maintainer aims to acknowledge reports within 72 hours. Confirmed entries are removed or relinked to a safe source, and the commit message records the reason.
